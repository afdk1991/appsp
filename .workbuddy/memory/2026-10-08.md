### 本轮最关键的坑（务必记住）
- **CSS 里混进字面 \n**：此前做字符串替换时把它当转义写入，整条 CSS 规则被破坏，
  而**类型检查和构建都不会报错**，只有运行时样式失效才暴露。
  教训：跨行写入一律用真实换行，写完用 `grep -rnF '\n' src/` 扫一遍。
- **`.gitignore` 不支持行尾注释**：`dist_*/   # 注释` 整行会被当 pattern，规则静默失效。
  写完必须用 `git check-ignore -v <path>` 验证。
- **store 里存对象引用**：`createOrder` 直接存 `state.addresses[i]`，改地址会连历史订单一起变。
  快照类数据（订单的地址/商品行）必须深拷贝。
- **API 返回必须校验形状**：`(res.data || []).map` 在后端返回错误对象时抛 TypeError，
  页面 catch 到的是类型错误而非网络错误，表现为白屏 + 提示错位。
- **uni-app 传感器/硬件 API 必须在 `onMounted` 里启动**，setup 阶段页面实例未就绪会直接 fail。
- **`onMounted` 从 `vue` 导入，不是 `@dcloudio/uni-app`**（只有 onLoad/onShow/onUnload 等页面生命周期在 uni-app 包里）。
